# 单细胞marker气泡图加突出框

A marker dot plot with expression color, percent-expressed size, and three highlighted cluster regions.

## Application

Compare marker expression across named cell clusters while emphasizing selected cluster blocks.

## Data boundary

A DotPlot-style table with avg.exp, pct.exp, features.plot, id, and avg.exp.scaled columns. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
