# Nature风格分组DEG条形图

A three-time-point grouped DEG bar layout with color-coded cell-type classes.

## Application

Compare differential-gene counts across three time points and cell-type groups.

## Data boundary

Synthetic cell-type rows with SNI_3day, SNI_3week, SNI_3month, and Group columns. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
