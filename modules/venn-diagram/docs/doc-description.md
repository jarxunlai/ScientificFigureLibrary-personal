# Venn图

用重叠椭圆比较 3–5 个名单的交集与差集。适合已经整理好的基因、突变或样本 ID 列表，想一眼看到独有与共有规模时使用。图上数字是集合计数，不是统计检验。本条目 preview 由 organized.R 渲染，例子为 sample() 模拟词表，不是论文结果。

## 应用

- **差异基因名单对照。** 处理 vs 对照、两种算法或两个时间点各自得到一组基因后，看三组重叠核心与各组独有基因规模。
- **突变 / 通路命中。** 比较多个队列或注释来源命中同一基因集的程度；四、五集合图用于更多名单，但交叉区会变挤。
- **方法一致性。** 同一分析换阈值或软件后，重叠比例可提示结果稳不稳；本模板用模拟词表，只提供画法。

## 数据

无外部表。脚本内 sample() 生成 5 个长度 200 的 word_<1-1000> 字符串集合。

本条目提供绘图示例，不代表上游分析或科学结论已验证。
