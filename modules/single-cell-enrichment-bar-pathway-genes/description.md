# 单细胞富集分析条形图（通路+基因）

A reusable labeled enrichment-bar function with pathway names, contributing genes, and cluster blocks.

## Application

Compare top enriched pathways across selected cell clusters with direct labels.

## Data boundary

A long-form enrichment table with Cluster, Description, pvalue, geneID, and optional enrichment fields. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
