# 开放式径向多轨注释图

## 需求描述

一个可编辑的 R 绘图模板：约 270° 的开放式径向图包含两条定量 signature median/IQR 轨道、一条二分类轨道和两条分类注释轨道。左上开口处，各 annular track 延伸为共享半径边界的竖向摘要槽，使箱线摘要和 stacked strips 与圆环保持连续。

## 应用场景

- 单细胞或空间组学中，以 cluster 为单位同时展示 signature score、恶性状态和多套细胞类型注释。
- 比较模型预测与作者/专家标签，并保持 cluster 顺序一致。
- 用于多组学样本、物种分类或表型审计中连续指标与分类轨道的联合汇总。
- 适合需要开放圆环与端点摘要槽相互对应的高密度补充图或总览图。

## 数据特征

一行对应一个 cluster。需包含显示顺序、cluster ID、二分类状态、模型标签、作者标签，以及 positive/negative 两组 q25、median、q75。随附 CSV 为 35 行确定性示例数据；signature 数值和二分类为合成数据，不代表真实临床或生物学结果。
