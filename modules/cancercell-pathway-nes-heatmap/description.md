# Cancer Cell通路NES热图

A portable ComplexHeatmap module for comparing pathway normalized enrichment scores across four subtypes.

## Application

Compare pathway NES values across A–D subtypes with category annotations and significance marks.

## Data boundary

A pathway table with Pathway, Category, A, B, C, D, and significance-marker columns. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
