# GSEA打分排序图

A ranked GSEA normalized-enrichment-score bubble scatter using a bundled synthetic pathway table.

## Application

Show ranked pathway NES values with point size and transparency encoding.

## Data boundary

A pathway table with ID, NES, setSize, and pvalue columns. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
