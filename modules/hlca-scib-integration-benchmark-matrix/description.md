# HLCA scIB 整合基准总表

A reproducible benchmark-table visualization for comparing integration metrics and weighted scores.

## Application

Compare batch-correction and biological-conservation metrics across integration methods and preprocessing settings.

## Data boundary

A newly generated scIB-shaped metrics table used to demonstrate the weighted score display. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
