# 十种相关性图复刻案例总览

Correlation case-study collection

## 科学问题

不同变量维度与数据结构应选用何种相关性表达？

原文是案例汇总，不是一个独立的第八类图。保留其11个可见图片块：8块映射到本批已重画的相同主题，另外补齐能量—寿命分组散点、四面板配对海洋指标、配对协调图与边缘密度。

## 应用场景

- 对照散点、矩阵、聚类、气泡和Mantel网络选择合适模板。
- 作为模板审阅入口，比较同一统计目标在不同维度下的展示方式。
