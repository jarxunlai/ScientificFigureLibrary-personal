# 暗夜密度热力UMAP

A dark-background density UMAP with white cluster ellipses and direct labels.

## Application

Show density hotspots and cluster boundaries in a single-cell embedding.

## Data boundary

Synthetic cell-level coordinates with cell, UMAP_1, UMAP_2, celltype, and group columns. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
