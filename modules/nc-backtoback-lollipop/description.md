# NC背靠背棒棒图（LHSC）

A back-to-back lollipop panel for comparing marker impact scores between two groups.

## Application

Compare marker scores for a selected cell type across two named cohorts.

## Data boundary

Synthetic marker-level rows with celltype, group, marker, impact score, EC score, and specificity. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
