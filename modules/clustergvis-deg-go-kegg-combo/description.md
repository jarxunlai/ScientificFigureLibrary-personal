# 差异基因聚类热图加GO和KEGG注释

A ComplexHeatmap module showing clustered synthetic expression patterns with GO and KEGG text annotations.

## Application

Present cluster-level expression patterns, marker genes, and pathway annotations in one composite panel.

## Data boundary

Synthetic Z-score and pathway tables are bundled as reproducible example inputs for the plotting layer. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
