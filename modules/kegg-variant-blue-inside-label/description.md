# KEGG变体条形图（蓝黄红柱内标签）

A labeled KEGG enrichment bar variant with a blue-yellow-red gradient and black in-bar pathway names.

## Application

Display ranked pathway enrichment with readable labels placed inside each bar.

## Data boundary

Fifteen synthetic pathway descriptions with adjusted p-values. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
