# 方形坐标轴UMAP

A square-axis UMAP with direct cluster labels and a fixed symmetric coordinate range.

## Application

Present a compact, equal-aspect embedding with stable axis limits.

## Data boundary

Synthetic cell-level UMAP coordinates and cell-type labels. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
