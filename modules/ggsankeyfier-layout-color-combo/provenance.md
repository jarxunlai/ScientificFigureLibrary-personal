# Provenance and cleaning boundary

## Reference

The visual layout and API clues were informed by the public article:
<https://mp.weixin.qq.com/s/PidcbXZv4h56V26IxmkTuA>.

The article did not provide a complete runnable script or the original tables.
This module is therefore a clean-room, visual-inference example rather than a
reproduction of the article, a book page, or any cited paper figure.

## Distributed scope

The distributed module contains only the files declared in `module.yml`:
cleaned R code, small synthetic CSV inputs, documentation, and generated PNG/JPEG
previews. The source screenshots, book pages, PDFs, reference images, original
unredistributed code, real experimental data, and local environment state are
intentionally excluded.

The code is MIT-licensed. The synthetic content, generated previews, and
module documentation are CC BY 4.0. These decisions apply only to the listed
clean-room files and do not grant rights to external reference material.
