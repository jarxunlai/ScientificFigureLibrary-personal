# ggsankeyfier 桑基图布局、配色与组合

用同一套 `ggsankeyfier` 语法演示基础两列流向、带间渐变、四列多层级流向，以及桑基节点与通路富集气泡的垂直对齐。示例输入全部为合成数据；代码是可读的版式整理和 visual inference，不是外部来源的原始分析脚本。

## 适用场景

- 检查两列或多列桑基图的节点顺序和边宽度。
- 使用节点两端的颜色构造带间渐变。
- 将多个阶段的流向排列在同一张图中。
- 让通路富集气泡与桑基右侧节点的 y 位置保持一致。

## 重要限制

本模块不包含书页、文章截图、参考图片、PDF、原始未授权代码或真实实验数据。合成流量、p 值、hit ratio 和 count 仅用于版式示例，不能作为科研结果或原始论文数据引用。
