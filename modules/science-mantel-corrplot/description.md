# Science风格Mantel网络相关热图

A correlation heatmap with Mantel links, significance colors, and effect-size widths.

## Application

Relate environmental variables to grouped composition blocks with a compact network overlay.

## Data boundary

Two synthetic numeric tables: a composition matrix and an environmental-variable matrix. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
