# 单细胞GO富集彗星图（分面）

A faceted comet plot for displaying enrichment results separately by cell cluster.

## Application

Show cluster-specific pathway enrichment with independent facet scales and count labels.

## Data boundary

A fully synthetic long table with Cluster, Description, Count, pvalue, and -log10(p) fields. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
