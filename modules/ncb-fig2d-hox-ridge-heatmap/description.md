# HOX前后轴山脊图加热图

A four-panel HOX expression module combining ridgelines and an average-expression heatmap.

## Application

Display spatial expression trends along an anterior-posterior axis for HOX groups.

## Data boundary

A synthetic gene-by-position CSV with one expression value for each AP layer. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
