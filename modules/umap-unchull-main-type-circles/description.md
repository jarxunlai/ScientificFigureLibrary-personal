# 单细胞UMAP大群虚线非凸包

A UMAP module with colored main-type hull outlines, subcluster labels, and a compact coordinate cue.

## Application

Show broad cell-type territories around subclusters in a synthetic embedding.

## Data boundary

Synthetic cell-level coordinates with subcluster and main-cell-type columns. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
