# 单细胞百分比差火山图加GO条形组合图

A cleaned plotting-layer module combining a percentage-difference bubble scatter with directional GO bars.

## Application

Show fold-change and percentage-difference signals beside a compact directional pathway panel.

## Data boundary

Two example tables: DEG rows with fold-change/percentage fields and GO rows with direction and bar coordinates. The included inputs are for plotting-layer demonstration and do not assert reproduction of an upstream analysis or scientific conclusion.

## Distribution boundary

Only the files declared in `module.yml` are distributed. Source/reference images, PDFs, internal Library records, logs, credentials, and machine-local state are excluded.
