# 系统发育树与微生物丰度箱线图

## 需求描述

在扇形系统发育树外围，按树叶顺序对齐各分类单元的丰度箱线图，同时用一致的颜色表达菌门分类。

## 应用场景

- 在具有树结构和丰度观测的微生物数据中，对照亲缘关系与丰度分布。需保留有效生物学重复，不能把合并后的观测自动解释为独立样本。
- 本示例展示包内数据经过筛选、合并和聚合后的布局；箱线图只包含丰度小于 120 的观测，不代表完整丰度分布或相对丰度百分比。

## 数据特征

使用 phyloseq 包内 GlobalPatterns 数据；保留总丰度大于 600 的分类单元，按 SampleType 合并，固定种子 394582 稀释，再按 Order 聚合。树叶分类与箱线观测通过 OTU 对应。
